## 已包含

- 完整4.0模板源码、固定参数、检查与渲染入口。
- 本地共享动效原始资料和截图，以及模板已有的帧驱动适配。
- 2个系列、18个自制动效组件，含源代码、入口、独立预览和系列公共素材。
- 非人物的示例图片、视频、磨砂材质和说明图形。
- 图片轮播的标签/说明分区布局，以及每个画面边界的轻量转场。
- 自带视频审片台，渲染检查通过后自动载入并打开，支持框选、时间点批注和汇总返修。只链接渲染目录的原视频，不复制或备份视频；会话仅保存当前源路径等必要信息。

## 安装与使用

Windows和macOS使用同一套Skill与工程。先识别本机系统和架构，运行`npm run setup`，优先复用已有工程依赖、共享运行组、本机工具与浏览器缓存，只准备缺失部分。日常渲染不需要Python或NumPy。

把本仓库地址交给Codex，并说：“安装仓库中的skills/xiaoteng-storyboard-style-4-0。”

安装后提供文案、SRT或词元时间轴及原始音频，并说：“调用小滕分镜风格4.0版，制作这一期分镜视频。”Codex按Skill创建独立学员工程，检查现有环境，准备必要依赖和字体，按本期内容选择组件、轮播图片与转场，再渲染并打开审片台。

## 制作与审片

学员提供文案、字幕时间码与原始音频，Skill按4.0风格及文案语义设计布局，让画面动作与原录音同步。首次`npm run setup`，后续可直接调用模板正式render入口；仓库纯画面演示使用`npm run render:demo`。

保留字体、素材、时间线、轻量排版与输出规格检查。文字应完整留在框内，独立文本框不重叠、不遮挡；渲染时发现排版问题及时提示。按CPU和内存自动选1或2并发，1920×1080、30fps、CRF16沿用原设置。

渲染后从实际视频生成带时间点的预览合集图，打开检查一遍，再由学员在自带审片台检查画面和声音。提供录音时审片视频带原始音频，用户确认后再完成验收。

## 文件管理

Skill位于skills目录，可与其他模板共存。每期源码、素材、规划、预览、成片分目录保存；共享动效库按三位编号管理，自制组件按S系列和全库唯一Z编号管理。新增系列从S003开始，新增组件从Z019继续。新期内容不覆盖组件库，更新Skill不覆盖学员已经编辑的项目。

字体、node_modules、浏览器和缓存不在仓库内打包，按明确依赖清单在学员本机按需准备。FFmpeg/FFprobe可复用本机工具或Remotion自带的对应系统版本；不需要Python或NumPy。源代码和正式素材随包保存，不依赖作者电脑路径。共享原始条目保持实际完整性状态，未适配条目需完成当期适配后才能计入成片。

本包不包含人物组件或专属品牌画面；Skill名称按课程名称保留。素材与第三方原始条目的来源和权利说明见[NOTICE](NOTICE.md)。
