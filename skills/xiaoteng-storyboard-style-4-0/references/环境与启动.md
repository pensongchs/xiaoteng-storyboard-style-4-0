# 环境与启动

仓库的Skill入口是`skills/xiaoteng-storyboard-style-4-0/SKILL.md`。把仓库地址交给Codex，要求安装该目录即可；安装目录与项目目录分开，已有其他风格Skill可共存。

首次使用，在用户指定位置或当前项目outputs内创建独立学员工程：

```bash
node "<Skill目录>/scripts/init-project.mjs" "<学员工程绝对路径>"
```

已有本学员工程继续在原目录工作。`--resume`只补充缺失文件，不覆盖已有内容；不要把空白示例再次覆盖到学员已编辑的项目。

需要Node.js 22.12以上（建议24）、FFmpeg/FFprobe、Python3.11以上及NumPy。Node包版本在工程package.json和package-lock.json中锁定，Remotion相关包均为4.0.484。先检查现有工具，复用可用依赖；缺失时由执行任务的Codex按目标系统准备，不复制作者的运行时。

如果存在全局`~/.codex/shared-node-dependencies/ensure.mjs`，先运行它并传入工程绝对路径，使用共享运行组；否则在学员工程执行`npm ci`。不要在已链接的共享node_modules内直接改包。

在工程目录执行：

```bash
npm run prepare:project
npm run doctor
npm run check
npm run render:demo
```

`prepare:project`从已验证的官方地址下载阿里健康体2.0，并校验字体包及45R/85B摘要，准备系列公共素材。中文、数值与立体数字采用同一字体家族的相应字重，避免依赖某台电脑的商业系统字体。下载的字体只留在学员本机，不随仓库分发；字体来源及摘要在`scripts/font-sources.json`。

首次渲染自动准备与固定Remotion版本匹配的Chrome Headless Shell，不使用老师电脑上的浏览器路径。可通过`REMOTION_BROWSER_EXECUTABLE`指定本机已验证的可兼容浏览器；Python可通过`PYTHON`指定。Windows、macOS与Linux均用本机路径和工具；任何平台都须以本机doctor及实际渲染结果为准。

审片台只链接原视频，使用源文件路径与SHA刷新，不复制、备份视频或另建审片成片。仅保留当前会话信息，批注用于本期返修。渲染后自动打开本学员工程审片台，优先使用4328端口；如果该端口属于其他工程，自动选择独立空闲端口并输出实际地址。手动恢复用`npm run station`。自动化或无图形环境可设置`NO_OPEN=1`，输出URL后手动打开。检查失败时先修复，不跳过校验交付。

## Windows与macOS

两个平台使用同一份工程、字体下载和渲染入口，不需要复制系统字体或作者浏览器。Windows使用可用的Python解释器路径或py启动器，程序会自动查找工程.runtime/python/Scripts/python.exe；macOS查找.runtime/python/bin/python。首次缺NumPy时可在该目录创建Python虚拟环境，由Codex安装NumPy；FFmpeg与FFprobe按本机系统准备并确认PATH可调用。路径中中文和空格受到支持，命令参数使用完整引号，不手工拼接带反斜杠的浏览器URL。

运行node scripts/check-portability.cjs可以核对Windows/POSIX路径编码。此项属于跨平台路径与代码检查，不等于已经在另一种系统完整渲染；实际使用还须通过本机doctor、排版和逐帧检查。
