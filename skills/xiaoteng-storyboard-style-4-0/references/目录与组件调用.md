# 目录与组件调用

唯一工程结构：

```text
学员工程/
  package.json / package-lock.json
  scripts/                         环境准备、检查及审片入口
  outputs/
    动效素材库/                     原始代码、截图、署名和登记表
    分镜素材制作/
      4.0模板/                      同一套风格、组件与检查入口
        自制动效组件/
          组件索引.json / 组件目录.md
          S001_基础磨砂系列/Z001～Z003/
          S002_玻璃关键词系列/Z004～Z018/
          S002_玻璃关键词系列/公共/
      分镜规划/{期名}/              本期契约、真实词元、动效调用和内部检查
      预览图/{期名}/                需要保留的正式预览图
      remotion-test/
        src/                        本期源码及独立注册入口
        public/{期名}素材/          本期图片、视频和材质
        public/fonts/               本机下载的字体依赖
        public/系列素材/            准备脚本接入的系列公共素材
        renders/{期名}/             实际成片
      src/                          审片台界面
      public/review-sessions/        本机审片会话，不入库
```

新一期先确定期名，检查有同一期时续接。只新建本期src入口、public素材和分镜规划；运行依赖和模板公共实现继续共用。输出数量、分段和时长遵从用户；不要为了动效多而拆成很多交付视频。

共享库先看登记表，再读相关条目截图和原始源码。已适配API见模板`组件/LibraryContent40.tsx`、`Library40.tsx`、`Glass40.tsx`及`Style40.tsx`，图片与说明分区的轮播入口为`StudentExtras40.tsx`的`CarouselCaption40`。未适配的原始资料保留原本完整性状态；每期选择后完成帧驱动适配、预览和来源登记再计数。

自制库的Z编号全库唯一，S编号区分系列。目前18项，下一系列S003、下一组件Z019。按组件目录定位`源码/组件.tsx`，与同系列必要公共代码和素材一起调用。不要只拿预览截图替代实现，也不将某期内容写回库内。

S001：Z001为Capsule短语标签，Z002为PearlCard信息卡，Z003为GlassPanel自由内容面板。参数与4.0设计坐标一致，触发at使用毫秒，g使用源帧。

S002：Z004～Z018导出同名组件；新期显式传入`content`、`accent/tone`、`illustration`和触发时刻。一般框型用`content.title`；Z009还需`lines`作为第二行，Z012清单用`lines`，Z015并列框用`columns`。插图支持`none`、`graphic`（route/location/home/guard）及本期本地图片。没有指定插图时自动收回插图区。

```tsx
<Z008 frame={g} atMs={触发毫秒} durationInFrames={持续帧数}
  content={{title:'风险边界',highlight:'风险'}} tone="risk"
  illustration={{kind:'none'}} x={72} y={320}/>
```

父层由4.0统一缩放，组件不重复缩放。使用学员示例中的SelfAuditBridge方式将S002归档标记接入4.0字面与排版检查；或实现等价的明确审计接入，不能绕过文字、框体和图片安全区检查。

每期至少5种不同共享库编号，轮播计入该数量；自制Z组件和原创MG分别统计。动效调用.json记录真实源文件、镜头和时间段，契约引用该清单。任何所谓“调用”都必须在成片中可见并有真实状态变化。

只有SRT时可运行模板准备输入.cjs，输出保留句级时码的本期JSON。此时beat使用cueIndex与句首，不填写尚无真实词元支持的word。
