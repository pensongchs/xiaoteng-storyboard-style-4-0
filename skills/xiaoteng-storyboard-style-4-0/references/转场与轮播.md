# 转场与轮播

每期至少一个图片轮播动效。优先使用已适配的032；需要其他形态时从033、043、055、057等原始资料中选择，先完成本期适配与验证。图片必须与当句对象、步骤或论据相关；至少两张不同图片，每张包含`file、label、description、atMs`，不要轮播无关建筑画面。

默认使用左侧关键词、右侧图片、图片下方说明的三块区域。图像保持比例和清楚主体；主标题、说明、圆角、阴影与4.0协调。较长说明换行、增高或改为上下结构，不无限缩小字体。说明区不压在图片关键主体上，文字卡与图片区留出明确间距；图换到哪张，标签和说明同步切换。

契约声明`carousel:{scene,kind,items}`，该镜头assets包含每张图片，screenText包含实际说明文字，动效调用清单登记对应轮播编号。示例的`CarouselCaption40`保留032景深递进、倾斜和前卡淡出，并将说明与图片分区。

所有相邻不同画面都有转场。默认6～20帧，常用12帧；按比较、章节变化或同一对象推进选择水平遮罩wipe或中心遮罩iris。不要只改Scene参数却继续裸切，也不要给普通关键词替换强加全屏转场。

用`transitions:[{atMs,kind,frames}]`逐个记录画面边界，并在完整画布层调用`SceneTransitions40`。该实现先遮住上一镜，再在同一源时刻切换，随后露出下一镜；使用暖中性材质和细强调边，不移动整段源字幕、不扣减总帧数、不提前显示下一镜核心文字。

转场安排在边界附近，旧画面退出和新画面进入的阅读时间均从本期真实时间预算中承担。短镜头可缩短转场，仍需保持清楚可见的衔接；信息量太大时调整镜头布局和内容，不篡改字幕时码。转场内也检查字体、图片、字幕区和像素稳定性，完成源头和成片的关键帧复核。
