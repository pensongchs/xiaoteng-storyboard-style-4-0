# 小滕分镜风格4.0版

这是可独立运行的学员版本，画面使用中性内容与说明图形。使用本包的模板和两套组件库；不读取或覆盖其他人的自用模板、目录、身份素材或审片记录。

## 开始与工程入口

先读当前任务目录的AGENTS.md。首次使用按[环境与启动](references/环境与启动.md)创建独立工程、准备固定版本依赖和官方字体；续接已有学员工程，保留当前内容。所有运行路径从本Skill或学员工程位置解析，不使用作者电脑路径。

读取学员工程的`outputs/分镜素材制作/4.0模板/模板总指令.md`，按[目录与组件调用](references/目录与组件调用.md)定位本期、共享库和自制组件。详细布局和固定参数以工程内同一份模板及实际代码为准。

## 制作要点

- 先理解文案，再按提问、比较、风险、数据、步骤或品质关系安排画面。保留4.0字面、层级、材质、统一内容层和底部字幕区；每期重新布局，不照抄示例的镜头顺序或具体台词。
- 每期实际调用至少5种不同共享库效果，其中至少一种为图片轮播。其他内容通常以约80%的自制组件、20%的内容MG搭配；用户指定比例时以当次要求为准，按内容单元记录，不能冒称播放时长比例。
- 图片轮播至少两张与文案相关的不同图片，逐张配标签和说明，图片区和文字区分开规划；检查文字与图片、卡片之间的遮挡和间距。
- 每个不同画面之间都有轻量转场，依据[转场与轮播](references/转场与轮播.md)配置。保留真实时间线和整片时长，不靠重叠扣减源时间或提前显示下一镜关键词。
- 新文案显式传入关键词、语义色、图片和时码。使用本包的归档实现及公共素材；原始共享库里未适配或缺少主结构的条目，需先完成本期适配并验证，不能仅导入或列编号。
- 以真实毫秒和词元驱动画面，30fps统一使用ceil(ms×30/1000)。无词元时使用句级动作，不均分句子伪造精确触发。遇到明显字幕错字只修文字，不擅自改时码。

## 渲染与审片

将本期契约、词元、轮播、转场和来源记录放在本期期名目录，运行模板的`check`与正式`render`入口。完成字体、素材、排版、每帧三次一致PNG、编码连续性、完整解码、黑帧、无音轨与共享动效实际可见检查。

正式渲染通过后，入口会自动启动或复用本学员工程的审片台，载入最新MP4并打开页面。使用实际输出文件与SHA刷新缓存；审片台只链接原视频，不复制、备份视频或另建审片成片；会话仅保存当前源路径等必要信息；不自动播放或代用户验收。需要返修时按批注时间与选区修改同一期，并重新载入。交付可直接观看的视频与简短说明。
