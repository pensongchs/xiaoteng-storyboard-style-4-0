## 视频调用规则

- 推荐用于确认、执行、审核通过、风险解除、完成校验或最终结论等需要“过程积累→完成反馈”的状态表达；删除只是原始示例，不限定实际用途。
- 不推荐用于普通导航、没有等待过程的瞬时动作、长句正文，或连续出现多个同类长按按钮的画面。
- 原效果依赖持续按住、释放和完成回调。正式用于视频时改成按字幕时间轴自动完成“初始状态→波浪进度填充→完成确认→短暂停留”，不等待鼠标或触摸，也不因松手回退。
- `Hold to delete` 和 `Deleted` 必须换成当期中文状态文案。按钮宽度、字体、字号、字重和左右留白按较长的一段文字统一计算，避免切换时尺寸跳动。
- 保留原紫色、波浪方向、填充节奏和完成光晕；选用于确有过程积累与完成反馈的台词。原效果的强度与画面不合时改选其他动效，不弱化波峰或重配颜色。
- Remotion 接入时用当前帧计算填充比例、波峰位置、缩放、光晕、完成脉冲和文字切换，不保留长按事件、释放事件或实时 DOM 尺寸作为动画驱动。
- 本效果定为 L2 结构性动效，接入工作量中等。进度填充是主要运动，完成脉冲只出现一次，不叠加额外粒子或持续闪烁。
