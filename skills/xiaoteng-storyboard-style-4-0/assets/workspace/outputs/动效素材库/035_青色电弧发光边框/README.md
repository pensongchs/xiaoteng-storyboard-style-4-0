## 代码与素材状态

- 主组件和 CSS 已提供；仅导入 React 和同目录 CSS，无外部动画库或图片依赖。
- 电弧由 Canvas 2D 沿圆角矩形绘制，通过噪声和动画时间产生扰动；使用 `ResizeObserver`、`requestAnimationFrame` 和设备像素比。
- CSS 使用多层模糊光晕、渐变背景及 `oklch(from ...)` 相对色语法。
- 调用颜色为 `#7df9ff`；组件自身默认颜色为 `#5227FF`，原样保留。
- 调用片段传入 `thickness={2}`，但当前组件未读取该属性，Canvas 线宽固定为 1；CSS 光晕边框为 2 像素。
- 调用片段通过 `style` 设置圆角 16，当前 Canvas 绘制读取独立的 `borderRadius` 属性，默认值为 24；两者存在参数差异，原样归档。
- 截图展示完整中文信息卡；调用片段仅包含英文说明段落，截图中的标签、标题、按钮及内容卡排版未随附。
