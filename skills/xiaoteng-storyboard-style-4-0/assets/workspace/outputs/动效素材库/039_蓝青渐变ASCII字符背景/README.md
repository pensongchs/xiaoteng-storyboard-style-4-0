## 代码与素材状态

- 主组件、调用片段与 CSS 已提供；源码仅导入 React 和同目录 CSS，无外部图片或动画库引用，未指定 React 版本。
- 通过 WebGL 2 与内嵌 GLSL 着色器合成渐变色场、ASCII 字符、辉光、闪烁和颗粒；字符图集由 Canvas 生成。
- 默认字体依次为 `Geist Mono`、系统等宽字体；未附 `Geist Mono` 字体文件或下载样式，实际字形取决于运行环境已有字体。
- 源码支持 `horizon`、`pinch`、`rise`、`eclipse` 四种形状，以及 `none`、`wave`、`burst` 三种点击效果。
- 调用片段原样保留蓝、白、浅蓝、青色四色，`horizon` 形状、字符集 ` =+xX0S8#@`（含首个空格）、600 像素容器高度、单元格大小 18、密度 0.8、字形透明度 0.85、辉光 0.2、闪烁 0.2、颗粒 0.08、鼠标交互、点击波纹和入场动画。
- 依赖 WebGL 2、Canvas、`ResizeObserver`、`IntersectionObserver`、`requestAnimationFrame` 与指针事件；无 WebGL 2 上下文时退出渲染。
