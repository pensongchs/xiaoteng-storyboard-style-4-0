## 代码与素材状态

- 主组件、调用片段与 CSS 已提供；源码仅直接依赖 React，弹性运动由组件内部逐帧计算，不依赖外部动画库。
- 组件支持字符串图片地址或带 `src`、`alt` 的对象数据，并支持容器尺寸、卡片尺寸、横向扩散、旋转、弧度、自定义变换、悬停推开、聚焦缩放、弹性、入场延迟、描边、圆角、阴影和点击回调。
- 示例保留 5 张 Unsplash 网络图片、500 × 320 容器、200 像素卡片、85 像素扩散、10 度旋转、160 像素推开距离、白色粗边框和 0.6 弹性等参数。
- 示例图片只保留原始网络地址，未下载本地文件；图片数组使用字符串形式，因此示例本身没有提供替代文本。
- 组件包含键盘激活、焦点描边和减少动态效果处理；只有传入 `onCardClick` 时卡片才获得按钮语义和键盘点击能力。
- 当前仅完成原始文件归档与一致性核对，未安装依赖，未进行运行、预览、Remotion 适配或渲染验证。

## 用途与备注

- 视觉特点：多张方形图片卡以不同角度从中心弹性展开，悬停当前卡片时放大并将两侧卡片推开。
- 适合房源、建筑、户型、板块、案例和生活方式图片的成组展示与单张聚焦；不适合需要同时精确比较全部图片细节的场景。
- 原始组件、参数、网络图片引用和截图作为后续调用的视觉与动作基准；正式用于视频时，入场回弹与悬停推开需按对应视频模板改为时间轴自动触发。
