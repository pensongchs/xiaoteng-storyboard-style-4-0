- 原网页依赖 `hover` 提升按钮网点层和四边泛光透明度。
- 正式用于视频时，将亮线、网点和泛光的增强过程改为按视频时间轴自动触发，不等待鼠标操作。
- `Button` 只是原始示例文字。正式视频根据当期中文文案替换，并重新调整中文字体、字号、字距、按钮宽高和四周留白。
