## 视频调用规则

- 推荐用于首付、税费、装修、月供、备用金、家庭预算、资金来源或不同费用层级等“多笔资金归入同一家庭资金池”的解释，也可用于三项成本依次展开后揭示总压力。
- 不推荐用于没有资金分层语义的普通卡片、真实银行卡展示、需要同时精确比较大量数据的画面，以及实景主体已经复杂的镜头。
- Stripe、Wise、PayPal、姓名、公司、邮箱、卡号和余额都是示例内容。正式视频必须删除品牌与账户身份，替换为当期中文资金类别；不得展示真实银行卡号、账户、邮箱、余额或其他个人敏感信息。
- 原组件通过页面载入和两层悬停控制卡片入袋、整体展开、单卡抬高、卡号显示和余额揭示。正式用于 Remotion 时改成按字幕时间轴驱动：卡片随对应资金项依次出现，当前项小幅抬高，结论节点才显示合计或压力标签，不保留鼠标交互。
- 正式视频不得复刻“显示完整卡号”的交互。需要表达隐私、隐藏费用或资金揭示时，只使用抽象星号、模糊条或中文标签的显隐，不出现可识别账户号码。
- 原 `display: none / block` 的显隐按字幕节点映射为可渲染状态；保留原 `scale(1.05)`、卡片旋转和错层节奏，并按最大运动范围检查安全区。
- 删除支付品牌标识和账户示例信息后，保留原卡片、钱包和阴影的主要色彩关系；若品牌元素无法替换而又保持原画面特征，改选其他动效。
- 本效果定为 L3 高存在感动效，接入工作量高。整镜只使用一次完整展开，卡片数量原则上控制在 2—3 张，不叠加强 3D、粒子、持续漂浮或复杂转场。
