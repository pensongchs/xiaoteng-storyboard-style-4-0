## 用途与备注

- 视觉特点：深色圆角卡片组成图片网格，灰度图随聚光恢复彩色，边框与底面同步出现各卡片主题色。
- 适合多房源、多板块、建筑、案例和方案图片的逐项聚焦；不适合需要全部图片同时保持彩色和清晰比较的场景。
