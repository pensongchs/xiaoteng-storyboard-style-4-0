## 视频调用规则

- 原组件支持悬停、点击、聚焦和键盘方向键切换当前图片。
- 正式用于视频时，将当前项变化、宽度展开、灰度恢复、视差、倾斜和标签出现改为按视频时间轴自动触发，不等待任何人工操作。
- 默认示例图片不得直接用于正式视频；必须根据当期文案换成对应的本地图片或项目正式素材，并确认来源与使用权限。
- `Canyon / Ridgeline / Falls / Harbour / Skyline` 是示例标签。正式视频按当期中文文案替换，并检查中文字体、字号、标签宽度和安全区。
- 图片切换顺序和停留时长必须对应台词内容；当前项才展开和彩色显示，不能提前突出后续图片。
- Remotion 正式接入时，动画需要改为按帧驱动，不能直接依赖 GSAP 的实时计时结果。
