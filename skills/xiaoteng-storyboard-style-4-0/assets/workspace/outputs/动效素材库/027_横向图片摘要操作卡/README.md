## 视频调用规则

- 推荐用于楼盘、房源、板块、政策条目、材料或证据摘要的单项展示，适合“缩略图 + 三行短信息 + 当前状态”的紧凑结构。
- 不推荐用于长段正文、多项复杂数据、需要大图细节的镜头，或没有操作与状态语义却保留右侧按钮的画面。
- 原组件主要动态是悬停阴影变化。正式用于视频时按字幕节点自动触发原有阴影状态，不等待鼠标悬停；当期内容没有右侧操作语义时改选其他动效，避免把无意义按钮放入画面。
- 中间三条占位线不能直接作为正式内容。调用时根据当期文案替换为中文标题、核心数据和一句短说明，并重新处理字体、字号、字重、行距与截断方式。
- 示例图片必须换成本地正式素材并检查版权、裁切和清晰度；图片与文字内容必须对应，不能继续使用无关占位图。
- Remotion 接入时使用当前帧驱动入场、阴影和状态变化，不保留网页悬停作为触发条件。
- 本效果定为 L1 轻量动效，接入工作量低。卡片入场或状态点亮只选一个作为主要运动，避免在紧凑卡片中叠加多余效果。
