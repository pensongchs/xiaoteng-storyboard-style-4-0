## 视频调用规则

- 推荐用于恰好三项中的最终选择、当前等级、当前阶段、优先级或赢家结论，尤其适合三个短词之间依次比较后落到一个明确结果。
- 不推荐用于长句、超过三项的清单、需要平等展示全部信息的画面、普通步骤说明，以及实景主体已经明亮复杂的镜头。
- 原代码通过 radio 的 `checked` 状态和兄弟选择器切换滑块位置。正式用于 Remotion 时改为按字幕时间轴计算当前项，滑块位置、文字亮度、填充色和阴影按帧同步变化，不保留点击和悬停依赖。
- `Silver / Gold / Platinum` 只是示例文字。正式视频必须替换为当期中文短词，并根据最长文字重新计算宽度、行高和内边距；不把长句压进窄卡片。
- 保留原过渡曲线 `cubic-bezier(0.37, 1.95, 0.66, 0.56)` 的过冲和回弹；按台词自动触发，并为滑块原运动预留完整空间。
- 保留原效果的银、金、蓝状态色、玻璃材质和光晕范围；通过背景、留白和元素位置与当期画面融合，无法融合时改选其他动效。
- 本效果定为 L3 高存在感动效。每 20—30 秒最多使用一次，只放在关键选择或结论节点；滑块移动与发光是唯一主要强调，不叠加粒子、跳字或大幅缩放。
