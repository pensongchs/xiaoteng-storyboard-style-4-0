## 视频使用建议

- 适合表现门票、资格、名额、通行证、使用前后状态，以及“条件达成后核销”的结论。
- 默认时间轴：票卡轻微入场倾斜 → 票面信息停留 → 存根沿打孔线撕开 → 存根旋转下落 → 主票居中并变成已使用状态。
- 视频中不保留拖拽、键盘或指针跟随；根据口播节点自动撕开，Remotion 中按帧重建角度、纤维断裂、下落和票面状态。
- 图片、标题、日期、编号和说明必须换成当期真实中文内容，并按中文字体重新调整字号、行距和留白。
- 没有“资格、核销、撕票、分离、领取”语义时，不作为普通图片卡使用。
- 预计视觉强度 L3，接入工作量高。
