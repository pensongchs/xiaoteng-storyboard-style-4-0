## 视频使用建议

- 适合表现多套房源、多个板块、多个户型、方案对比、事件阶段或案例图片依次聚焦。
- 默认时间轴：卡组建立景深 → 当前图保持清晰 → 后排卡片向前递进 → 新主图停稳 → 标签或结论同步出现。
- 视频中不保留滚轮、拖拽、按钮和自动播放计时器；根据口播节点推进当前卡，Remotion 中按帧计算位移、景深、旋转、亮度和模糊。
- 图片必须使用可追溯的本地素材，并为每张图添加对应中文短标题；需要文字时放在独立信息层，不直接依赖图片内容。
- 同一镜头建议展示 3—5 张，避免纵深过密、背景模糊过强或频繁循环造成视觉疲劳。
- 预计视觉强度 L3，接入工作量中。
