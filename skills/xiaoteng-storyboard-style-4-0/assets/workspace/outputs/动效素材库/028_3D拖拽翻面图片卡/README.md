## 视频调用规则

- 推荐用于“表面现象→背后原因”“楼盘外观→核心数据”“户型图片→优缺点”“结论前→结论后”等正反两层信息揭示。
- 不推荐用于没有前后信息关系的普通图片、需要持续阅读两面的长文、多个翻面卡同时运动，或背景已经包含强烈透视运动的镜头。
- 原效果依赖点击、拖拽、鼠标位置倾斜和光泽跟随。正式用于视频时改成按字幕时间轴自动完成“正面稳定展示→轻微预倾斜→翻到背面→信息停留”，不等待人工操作。
- 正面图片和背面标题、说明必须根据当期文案替换；图片需使用来源明确的本地素材，背面中文重新处理字体、字号、行距、边距和安全区。
- 原示例 `tiltMax={12}`、`hoverScale={1.03}` 和动态光泽存在感较强。正式接入时根据镜头克制倾斜和光泽，保证翻面信息清晰且不引起眩晕。
- Remotion 接入时用当前帧计算旋转角度、倾斜、缩放、阴影和光泽位置，不保留点击、拖拽或指针坐标作为必要输入。
- 本效果定为 L3 高存在感动效，接入工作量高。翻面是唯一主要运动，避免同时叠加大幅卡片位移、连续镜头旋转或额外粒子。
