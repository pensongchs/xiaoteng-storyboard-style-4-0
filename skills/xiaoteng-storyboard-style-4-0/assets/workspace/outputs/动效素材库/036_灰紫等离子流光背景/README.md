## 代码与素材状态

- 主组件和 CSS 已提供；仅导入 React 和同目录 CSS，无外部图片或动画库依赖。
- 通过 WebGL 2 和内嵌 GLSL 着色器生成流动、扭转的体积光带，并进行颜色、光泽、颗粒和透明度合成。
- 使用 `ResizeObserver`、`IntersectionObserver`、`requestAnimationFrame`、页面可见性与指针事件。
- 调用片段设置灰紫色 `#a6a3b8`、600 像素容器高度、正向流动、质量参数 0.75、颗粒 0.04，开启鼠标交互和入场，关闭浅色模式；原样保留。
- 截图中的刷新按钮与“演示内容”开关属于示例页面界面，本次组件只返回背景容器与画布，未随附这些控件。
- 运行环境需要支持 WebGL 2；当前仅完成文件归档核对，未进行运行、预览或渲染验证。
