## 视频调用规则

- 原网页依赖 `hover`、`focus` 和 `active` 交互状态。
- 以后用户明确要求把本动效放进视频时，必须将这些交互状态改为按视频时间轴自动触发，不等待鼠标悬停、点击或键盘聚焦。
- 默认自动表现为：按钮进入画面 → 星光与文字依次发亮 → `Generate` 自动切换为 `Generating` → 发光状态保持或按当期节奏退出。
- 具体触发时间以当期文案、字幕时间码和镜头时长为准，不在素材归档阶段预先固定。
