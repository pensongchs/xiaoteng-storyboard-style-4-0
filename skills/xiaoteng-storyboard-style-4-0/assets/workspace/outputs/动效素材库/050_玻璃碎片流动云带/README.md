## 代码与素材状态

- 主组件、调用片段与 CSS 已提供；源码依赖 React、`vgpu`、浏览器 WebGPU、同目录 CSS 和内嵌 WGSL 着色器，依赖版本未指定，无外部图片引用。
- 调用示例保留紫色碎片 `#896ABD`、强调色 `#A855F7`、玻璃材质、全画面排布、加号标记、1300 个碎片、景深 0.75、暗角 0.3、辉光 0.35、颗粒 0.06 和 600 像素容器高度。
- 组件支持玻璃或铬材质、全屏或侧向排布、加号或圆点标记、鼠标视差、点击脉冲、长按聚拢、入场动画、暂停、尺寸、扩散、扭转、起伏、速度、比例及 DPR 调节。
- 组件使用 `ResizeObserver`、`IntersectionObserver`、Pointer Events 和减少动态效果偏好；不支持 WebGPU 时会通过 `onError` 报错。
- 截图为紫色玻璃碎片组成的多层流动云带，前后层带明显景深模糊，并叠加稀疏加号标记；截图中的深色底面属于展示环境，原组件默认背景为透明。
- 当前仅完成原始文件归档与一致性核对，未安装依赖，未进行运行、预览、Remotion 适配或渲染验证。

## 用途与备注

- 视觉特点：大量半透明碎片形成具有空间纵深的流动带状结构，结合辉光、颗粒、暗角和焦外模糊，呈现科技感与梦境感。
- 适合空间关系、数据流、复杂系统、城市网络、风险扩散和章节过渡背景；不适合需要稳定阅读的大段正文，或不支持 WebGPU 的目标环境。
- 原始组件、参数和截图作为后续调用的视觉与动作基准；正式用于视频时，鼠标、点击和长按交互需按对应视频模板改为时间轴自动触发。
