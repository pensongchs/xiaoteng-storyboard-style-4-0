## 视频调用规则

- 原组件主要是静态信息卡，仅底部操作按钮包含 `hover` 状态。
- 正式用于视频时，标签、标题、正文、元信息和按钮文字全部根据当期中文文案替换，并重新检查中文字体、字号、行距、层级、卡片宽度和内边距。
- 底部按钮需要状态反馈时，将悬停变化改为按视频时间轴自动触发；不需要操作语义时可以省略按钮，避免无意义装饰。
- 正文应压缩为适合视频阅读的短句，优先控制在一至两层信息；内容过长时拆镜，不能把口播全文塞入卡片。
- 图标必须与当期内容语义匹配，不能固定复用原示例的层叠图标。
