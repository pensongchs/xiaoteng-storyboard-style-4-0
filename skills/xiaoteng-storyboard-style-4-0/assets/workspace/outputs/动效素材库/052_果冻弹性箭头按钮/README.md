## 用途与备注

- 视觉特点：高饱和蓝色胶囊、浅蓝粗描边、手绘路径箭头和悬停时的果冻式弹性回弹，行动感清晰直接。
- 适合发现、探索、继续、前往、下一步和行动号召；不适合长文本、低对比背景或多个按钮同时频繁弹跳的场景。
- 原始代码和截图作为后续调用的视觉与动作基准；正式用于视频时，悬停和按下状态需按对应视频模板改为时间轴自动触发。
