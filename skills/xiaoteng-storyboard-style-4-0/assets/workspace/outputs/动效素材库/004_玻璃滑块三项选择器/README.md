## 视频调用规则

- 原网页依赖单选按钮 `checked` 状态和点击操作。
- 明确用于视频时，将选项变化与滑块移动改为按视频时间轴自动触发，不等待鼠标、键盘或触摸操作。
- `Silver / Gold / Platinum` 只是原始示例文字。正式视频根据当期中文文案替换，并重新计算每项宽度、中文字体、字号、字距和居中关系。
- 默认按旁白顺序逐项切换当前高亮，不提前点亮后续选项；具体停留时间以当期文案和字幕时间码为准。
