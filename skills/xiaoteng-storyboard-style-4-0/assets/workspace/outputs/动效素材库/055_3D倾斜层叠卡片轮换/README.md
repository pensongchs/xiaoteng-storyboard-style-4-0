## 代码与素材状态

- 主组件、CSS 与两种调用方式已提供；源码依赖 React、`@hugeicons/react`、`@hugeicons/core-free-icons`、浏览器动画帧、ResizeObserver 和 IntersectionObserver，依赖版本未指定。
- 组件支持 `items` 数据模式与 `<Card>` 自定义内容模式，并包含自动轮换、悬停暂停、拖拽、点击切换、方向键切换、视差、弹性、层级暗化、深浅主题和减少动态效果处理。
- 第一段调用里的 `delay={4000}` 重复出现，本次按用户原始调用保留；两处值相同。
- 调用示例引用 `/photos/sky.jpg`、`/photos/field.jpg`、`/photos/pier.jpg` 和 `/photos/clouds.jpg`，这些本地图片未随本次材料提供。组件自身还带有 4 张 Unsplash 网络默认图片。
- 截图显示 `Blue hour`、`Moonrise`、`Dusk`、`Pink drift` 四张卡片，与调用示例的标题和部分图片不一致；截图中的图标和图片素材未作为独立文件提供。
- 当前仅完成原始文件归档与一致性核对，未安装依赖，未进行运行、预览、Remotion 适配或渲染验证。

## 用途与备注

- 视觉特点：多张深色圆角图片卡沿右上方向错层后退，结合透视、倾斜、深度暗化和前后轮换形成空间层次。
- 适合房源、户型、建筑、板块、方案和案例图片的依次聚焦，也适合多项信息从后方轮换到前景。
- 不适合需要同时精确比较全部卡片细节的场景，或在画面空间不足时叠加过多可见卡片。
- 原始组件、参数和截图作为后续调用的视觉与动作基准；正式用于视频时，自动轮换、拖拽、点击和悬停状态需按对应视频模板改为时间轴自动触发。
