## 视频调用规则

- 推荐用于四项提醒、四个条件、四类成本、四个风险或四步判断从“汇总”展开到“逐项可读”的镜头。
- 不推荐用于少于或多于四项且不准备重做位移关系的内容、长段正文、需要同时密集比较的数据表，或只有单张卡片的画面。
- 原效果依赖复选框、点击开合和卡组悬停。正式用于视频时改成按字幕时间轴自动完成“卡组堆叠→四卡依次展开→当前卡聚焦→必要时重新收拢”，不等待观众操作。
- 四张卡的标题、条目、勾选状态和辅助文字必须根据当期中文文案替换，并重新处理字体、字号、行距、卡片高度与长文本换行。
- 当前 CSS 将位移与四列网格写死，并依赖固定的四个 `nth-child`。正式适配时若项目数量变化，必须重新计算卡片数量、位移、层级与展开宽度，不能直接复制现有百分比。
- Remotion 正式接入时使用帧驱动重建原有四卡堆叠、展开和轻微旋转；先通过整体尺寸和位置保证横向展开落在安全区内，仍无法容纳时改选其他动效，不缩减原卡片数量或保留网页滚动依赖。
- 本效果定为 L2 结构性动效，接入工作量中等。堆叠展开是唯一主要运动，悬停预览和按钮文字切换只保留与文案直接相关的部分。
