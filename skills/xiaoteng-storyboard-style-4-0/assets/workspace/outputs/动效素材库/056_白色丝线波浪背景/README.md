## 代码与素材状态

- 主组件、调用片段与 CSS 已提供；源码仅直接依赖 React 和浏览器 WebGL 2，无外部图片、字体或第三方图形库引用。
- 组件使用 WebGL 2 实例化绘制多条线带，并通过离屏纹理、Perlin 噪声、柔化、亮度曲线和透明混合形成连续丝线波浪。
- 调用示例保留白色、90 条线、0.6 线宽、1.3 柔化、1.7 振幅、25 度角、0.85 渐隐、1.4 亮度及鼠标影响等参数。
- 组件支持主色与强调色渐变、线数、粗细、柔化、振幅、间距、波数、速度、分叉、散开、角度、随机种子、鼠标拨开、末端渐隐、边缘淡出、透明度和暂停调节。
- 当前调用虽然开启 `enableMouseInteraction`，但 `parting={0}`，因此指针不会拨开线束，只保留对波形的鼠标影响。
- 组件包含最大渲染尺寸限制、ResizeObserver、IntersectionObserver、页面可见性处理和减少动态效果偏好。
- 截图为深色底面上的多层白色丝线波浪；深色底面未包含在组件和 CSS 中，属于展示环境。
- 当前仅完成原始文件归档与一致性核对，未安装依赖，未进行运行、预览、Remotion 适配或渲染验证。

## 用途与备注

- 视觉特点：大量细白线组成起伏、交错和分层的流动曲面，兼具数据网格、纤维和空间地形感。
- 适合数据流、空间关系、趋势变化、复杂系统、章节标题和短结论的氛围背景；不适合需要稳定阅读的大段正文或低性能设备上的高密度叠加。
- 原始组件、参数和截图作为后续调用的视觉与动作基准；正式用于视频时，鼠标影响、指针拨开和时间推进需按对应视频模板改为时间轴自动触发。
