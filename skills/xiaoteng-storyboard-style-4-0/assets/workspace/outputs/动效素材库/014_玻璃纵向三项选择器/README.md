## 视频调用规则

- 推荐用于恰好三项的方案、等级、条件、阶段、成本、风险或结论选择，也可用于三项依次排除后确认当前项。
- 不推荐用于超过三项的长清单、需要同时平等展示的并列信息、没有选择或状态变化语义的普通装饰，以及单项文字过长的画面。
- 原代码通过 radio 的 `checked` 状态、兄弟选择器和 `:has()` 驱动画面。正式用于 Remotion 时应改成由字幕时间轴计算当前项，高亮条、文字、勾选和颜色按帧同步变化，不保留点击依赖。
- `Silver / Gold / Platinum` 只是示例文字。正式视频必须换成当期中文内容，并按实际字数重新计算容器宽度、高亮条高度、三项间距和纵向位移，不能直接沿用固定的 `115% / 230%`。
- 保留原效果的银、金、蓝三套状态色、玻璃材质和高亮条层次；用画面外围的背景与留白协调，不把三项统一换成模板色。若三项状态不适合当前文案，改选其他动效。
- 当前项应在对应台词说到时移动并稳定，上一项可以降低亮度后保留，下一项不得提前高亮。勾选标记只代表明确选择或确认，普通步骤推进可改为圆点或序号。
- 本效果定为 L2 结构性动效。保留原高亮条移动和对应光影变化，不额外叠加与原效果无关的强运动。
