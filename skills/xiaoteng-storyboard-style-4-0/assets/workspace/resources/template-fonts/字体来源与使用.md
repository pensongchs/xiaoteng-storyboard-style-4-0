# 模板字体

本目录包含4.0模板实际使用的阿里健康体2.0中文：45 R（正文）和85 B（标题、标签及数字）。保留官方原文件与使用说明，字体版权归北京北大方正电子有限公司。来源、原包和文件摘要记录在工程`scripts/font-sources.json`。

官方介绍：[阿里健康体2.0，永久免费商用，开放下载](https://www.foundertype.com/index.php/News/newsdetails/id/141.html)。官方页面说明面向全社会（包括商业企业）永久免费开放使用。随包保留的《官方字体使用说明.pdf》说明字体家族与使用方法；本仓库不另行授予字体许可。

运行`npm run setup`或`npm run prepare:project`，自动校验并将本目录字体接入视频工程和审片台。无需安装到操作系统，Mac和Windows使用同一份字体文件。
